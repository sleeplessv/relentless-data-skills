# CLAUDE.md

## Agent skills

### Issue tracker

Issues (and specs) are tracked as GitHub Issues on `sleeplessv/relentless-data-skills` via the `gh` CLI; external PRs are not a triage surface. See `docs/agents/issue-tracker.md`.

### Triage labels

The six canonical triage labels are used verbatim: `needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`, `awaiting-verification`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context layout — one `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
